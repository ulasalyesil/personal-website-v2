## Findings considered and rejected

(Recorded so future audits don't re-litigate them.)

- **ResizeObserver leak in LabCanvas** — false: `ro.disconnect()` (LabCanvas.tsx:153) unobserves everything; the safe-area ref is stable and always rendered.
- **Inert `placeholder` flag on lab items** — false: `LabCard.tsx:57` reads `item.placeholder`.
- **Missing image dimensions in CaseStudyLayout causing layout shift** — false: `ImageBlock.src` is `StaticImageData` (types/index.ts:43); next/image infers intrinsic dimensions from static imports.
- **Scatter layout recomputes on items-array identity churn** — false: `LAB_ITEMS` is a module constant with stable identity.
- **`items.indexOf(item)` in LabCanvas render** — real but n=5; not worth doing.
- **Pre-commit hooks (husky/lint-staged)** — marginal for a solo repo once CI (plan 001) exists.
- **Missing `rel="noopener noreferrer"` as a standalone security finding** — real inconsistency, near-zero risk (modern browsers imply noopener on `target="_blank"`); folded into plan 008.
- **Replace luxon with `Intl`** — legitimate (~23 KB gzip for one component) but MED timezone-correctness risk for small payoff; not worth doing now.
- **tw-animate-css unused** — false: imported at `styles/globals.css:4`.
- **Uncommitted getirfinans-dark-mode WIP / placeholder images** — the maintainer's active work, not a finding.
- **Per-page metadata for client-component pages (`/`, `/about`)** — can't export `metadata` from `"use client"` files; restructuring pages just for titles isn't worth it (noted inside plan 009).
